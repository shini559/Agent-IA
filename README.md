# 📍 Agent IA ChatBot

Ce projet vise à développer un prototype fonctionnel d'un chatbot axée sur **l'emploie et l'insertion** à partir de données sur **l'Emploi, les formations et les salaires**.

Il s'appele **P'tibou** s'appuie sur un modèle **DeepSeek** et est construit via **LangChain**.

---

## 🚀 Objectifs

- Accompagner les utilisateurs sur les demandes liés à l'emploie et l'insertion
- Implémenter un modèle DeepSeek via une api pour gagner en efficacité et rapidité
- Affichage d'un historique des messages pour la traçabilité
- Mise en place d'une base de données
- Recherche d'informations par l'ia dans les fichiers fournies dans la base de données
---

## 🧠 Technologies utilisées

- Python 3.13+
- Langchain
- Streamlit
